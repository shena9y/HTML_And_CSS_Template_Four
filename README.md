# Elzero Dashboard — HTML & CSS Template Four

A complete, multi-page admin dashboard UI built with pure HTML & CSS. Built as the fourth training template from the **Elzero Web School** curriculum, it uses a custom CSS framework of utility classes (padding, colors, radius, flexbox helpers) alongside a master stylesheet to deliver a consistent design system across seven pages.

## ✨ Features

- 📊 **7 complete pages** — Dashboard, Settings, Profile, Projects, Courses, Friends, Files & Plans
- 🧩 **Reusable CSS framework** — utility classes (`d-flex`, `p-20`, `rad-6`, `bg-white`, …) for rapid layout building
- 🧭 Sidebar navigation with active-state highlighting
- 📈 Dashboard widgets: welcome card, yearly targets, latest news, projects progress, and more
- 🗂️ Files page with file-type icons (PDF, SQL, PSD, ZIP…) and stats
- 📱 Responsive layout powered by Flexbox

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Page structure & semantic markup |
| CSS3 (Flexbox) | Custom framework + master stylesheet |
| Font Awesome 6 | Icons (locally hosted webfonts) |
| Google Fonts — Open Sans | Typography |

## 📂 Project Structure

```
├── index.html        # Dashboard (home)
├── settings.html     # Site settings page
├── profile.html      # User profile page
├── projects.html     # Projects overview
├── courses.html      # Courses grid
├── friends.html      # Friends list
├── files.html        # File manager UI
├── plans.html        # Pricing plans
├── css/
│   ├── framework.css # Utility-class CSS framework
│   ├── master.css    # Main theme styles
│   └── all.min.css   # Font Awesome
└── imgs/ webfonts/   # Images & icon fonts
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shena9y/HTML_And_CSS_Template_Four.git
   ```
2. Open `index.html` in your browser — no build step required.
